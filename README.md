# BookApp

BookApp is a book website, the app is able to;

- Both server-side and client code connected.
- Create, Read, Update and Delete books.
- Read, Update and Delete users.

Connected services to BookApp include;

- DB (Postrgresql - coded using sequelize)
- S3 (Bucket Minio - coded using sequelize)

Extra Services include;

- Redis
- Docker
- And more

> **Note**: Application is still in development. As such bofore use, be notified that it has a couple of errors and disconnected functionable code.
