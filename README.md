# BookApp

BookApp is a book website. Both server-side and client code connected. The app is able to;

- Create, Read, Update and Delete books.
- Create, Read, Update and Delete users.

Connected services to BookApp include;

- DB (Postrgresql - coded using sequelize)
- S3 (Bucket Minio - coded using sequelize)

Extra Services include;

- Redis
- Docker
- And more

> **Note**: Application is still in development. As such before use, be notified that it has a multiple errors and disconnected functionable code.
